# Open-source project picks profile

Use this profile for new or newly popular open-source projects that a developer could actually try: developer tools, self-hosted apps, AI and agent tooling, CLI utilities, libraries, frameworks, and fun experiments.

Prioritize projects created or first gaining traction in the last 90 days. Established projects qualify only when they just shipped a major new capability or became newly relevant.

Typical items are GitHub trending repositories, Show HN launches, and project announcements with a public repository.

Do not use this profile for releases of established products, corporate open-source announcements without a usable project, non-open-source products, tutorials, or abandoned repositories.
