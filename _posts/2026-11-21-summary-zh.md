### [Firecrawl：为 AI Agent 提供网页抓取与交互能力](https://github.com/firecrawl/firecrawl) ⭐️ 8.0/10

Firecrawl 是一个开源工具包，用于抓取、搜索并与网页交互，为 AI Agent 提供“知识基础设施”。它提供 Python、Node.js SDK 和 CLI、cURL 示例，支持抓取页面转为 markdown、按自然语言提示操作页面，以及无需 URL 的 Agent 查询。仓库包含 Firecrawl Local（单个二进制文件）、自托管服务器（Docker Compose 带 Redis、PostgreSQL 和浏览器服务）及 SDK。主项目采用 AGPL-3.0，SDK 及部分 UI 组件采用 MIT。README 未提供星标数或近期提交信息，无法据此判断活跃度。

rss · GitHub Trending - Daily · 11月21日 23:02

**「适用场景」** 适合构建 RAG、研究助手或自动化采集流程的开发者：可以先用 \`scrape\` 抓取目标页面并拿到 scrapeId，再用自然语言指令完成搜索、点击等多步操作，省去自行维护无头浏览器和解析逻辑。

**「背景」** 部署在边境管控与机场监控中的人脸呈现攻击检测（PAD）系统，普遍建立在“被摄者距离很近、通常不足 1 米”这一假设之上。作者指出，目前尚无基准能系统覆盖多距离采集、多样环境条件，以及欺骗攻击与遮挡攻击同时出现的情形，因而实际部署的模型对真实场景准备不足。

**「方案」** 作者构建了一个视频 PAD 数据集：它包含 261 个身份的 374,000 余帧，覆盖 1 米至 100 米共五个拍摄距离和室内外场景，分别由单反相机（C）与手机传感器（M）采集，并标注活体、欺骗、道具遮挡三类；模型以视频片段而非单帧进行训练与评测。作者微调并对比了 MobileNetV3、MobileNet、EfficientNet 与 ResNet-50 四种 CNN 架构：高分辨率的单反在全部距离上对欺骗的分类几乎完美，而低分辨率的手机传感器在超过 50 米后性能急剧下降，MobileNetV3 对道具遮挡的分类率在 75 米处降至 55%。EfficientNet 综合表现最佳，准确率 98.48%、ACER 2.01%；在未见攻击数据集上的泛化测试取得 89%–94%的准确率，作者据此认为跨域鲁棒性得到验证。数据集将依据终端用户许可协议公开，以支持可复现的长距离 PAD 研究。

**「启示」** 作者的结论是：拍摄距离与传感器分辨率是决定 PAD 难度、却长期被忽视的两个关键维度，长距离、多传感器的系统化评测应成为这类系统走向真实部署的重要前提。
