### [AutoClip：开源 AI 长视频自动切片桌面工具](https://github.com/zhouxiaoka/autoclip) ⭐️ 8.0/10

AutoClip 是 MIT 许可的开源桌面应用，能把播客、访谈、课程等长视频自动剪成适配抖音、小红书、TikTok、Reels、Shorts 等平台的短片，并生成字幕、封面和发布文案。它基于 Tauri/React，配合 FastAPI、FFmpeg、yt-dlp 与 Whisper/FunASR 等技术；剪辑和渲染在本机完成。项目页展示 release 与 GitHub Trending 徽章，但未给出具体星数。

rss · GitHub Trending - Daily · 11月23日 23:02

**「适用场景」** 适合做播客、访谈或课程二创的创作者：贴入链接、选定平台后，工具会按评分生成至多 10 条候选片段，每条带封面、标题、简介、话题和 ZIP 发布包，省去逐条手剪与排版。它还提供 CLI/MCP，可接入自动化流程。

**「快速试用」** 从 GitHub Releases 下载桌面版（README 未提供一行安装命令），再用官网案例库的样片对照效果：https://github.com/zhouxiaoka/autoclip/releases/latest 。

**「注意事项」** 项目由个人维护，明确不提供即时客服，回复时间不固定；软件免费，但云端模型按量计费。README 中的耗时和费用是开发期单次实测，并非同一输入的对照。具体星数与近期提交活跃度未提供。

### [OpenVINO：跨平台 AI 推理优化与部署工具包](https://github.com/openvinotoolkit/openvino) ⭐️ 8.0/10

OpenVINO 是开源工具包，用于优化并部署深度学习推理：可将 PyTorch、TensorFlow、ONNX、PaddlePaddle、JAX/Flax 等模型转换后在 CPU（x86/ARM）、Intel GPU 与 NPU 上运行，提供 C++、Python、C、NodeJS API 及 GenAI 接口。许可证为 Apache-2.0。来源未提供 star 数或近期提交活跃度数据。

rss · GitHub Trending - Daily · 11月23日 23:02

**「适用场景」** 适合需要在 Intel 硬件或边缘设备上部署已有模型的工程师：用 ov.convert\_model 把模型转成 OpenVINO 格式，再用 core.compile\_model 指定设备推理，从而摆脱原训练框架的运行时依赖。

**「快速上手」** 从 PyPI 安装 openvino 包，然后照 README 中的 PyTorch 或 TensorFlow 代码片段做转换与 CPU 推理；完整文档见 docs.openvino.ai，GenAI 场景另有 openvino.genai 仓库与示例。

**「注意事项」** 该工具默认收集性能与使用数据（含 Google Analytics 4），可用 opt\_in\_out --opt\_out 关闭，企业部署前应确认合规。来源未给出最新版本号与维护节奏，成熟度建议自行核实。

据 BBC 娱乐报道，意大利珠宝商、企业家保罗·宝格丽去世，享年 89 岁。其家人在向意大利媒体发表的声明中悼念他，称他是“我们这个时代最伟大的珠宝商”。报道于 2026 年 11 月 23 日发布，内容以简短讣告为主，除家属的这句评价外，未披露更多细节。

**「背景」** 宝格丽这一姓氏同意大利高端珠宝与奢侈品行业紧密相连，是国际市场上最具辨识度的意大利品牌名之一。“最伟大的珠宝商”这一说法出自家属声明，属于家人的追思评价，而非第三方机构的评定。
