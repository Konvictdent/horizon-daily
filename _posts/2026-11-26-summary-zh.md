github · anefzaoui · 11月25日 23:02

### [保守重叠模糊粗糙集：面向不完整数据的属性约简](https://arxiv.org/abs/2611.31329) ⭐️ 7.0/10

**「背景」** 在不完整信息系统中，缺失值会破坏粗糙集理论赖以建立的等价类结构，因此属性约简变得困难。作者提出的保守重叠模糊粗糙集（COFRS）模型，正是要绕开这一结构性问题。

**「方案」** COFRS 用每个对象“当前存在的属性集合”来描述该对象。两个对象的相似度定义为它们在共有属性上的加权重叠，再除以固定的属性总数 \|A\|（而不是除以二者属性并集的大小），由此缺失值会被全局惩罚，而不会被当作通配符参与匹配。基于这一相似度，作者定义了以加权粒度一致性为基础的软依赖度，并用贪心后向消除在 O\(\|U\|²\|A\|²\) 时间内搜索约简。理论部分，作者证明该关系是对称但非自反的，依赖度并不单调，并给出一个保证单调性成立的充分条件。在 11 个缺失率介于 0.15% 至 20.46% 的 UCI 基准上，COFRS 平均得到最小的约简（4.1 个属性，而 Tolerance-RS、范围阈值变体 Tol-RS\_tau、Zhou-RS 与最小聚合变体 COFRS-min 为 5.0–11.2 个）；这一优势相对 Tol-RS\_tau、Zhou-RS 和 COFRS-min 显著（Holm 校正 Wilcoxon p&lt;0.01），相对 Tolerance-RS 不显著（p=0.56），相对 Jensen-Shen 选择器差异较小（校正 p=0.084）。在约简规模相同时，COFRS 选出的属性比随机子集包含更多信息。使用 kNN 分类器时，各方法在准确率、F1 和 G-mean 上无显著差异；使用 RBF-SVM 时存在显著差异，且 COFRS 排名最后。作者因此说明，其收益在于约简更紧凑，而非预测精度更高。

**「启示」** 作者的结论是：以固定属性总数对缺失值进行全局惩罚，能换来更紧凑的属性约简，但这种紧凑性并不自动转化为分类精度上的优势。因此，评估此类约简方法时，应把约简规模与下游模型的表现分开看待。

**「方案」** 作者把智能体能力拆成任务能力（解题所需知识与推理）和接口能力（通过特定 harness 采取行动），并在四个推理与智能体基准上考察二者如何相互影响。其核心发现是，多 harness 蒸馏虽能把不同 harness 轨迹中的任务知识聚合进共享策略，但只有当训练保留或提升推理时接口上的能力时，这些知识才会真正兑现；否则，单 harness 训练会干扰接口能力，甚至在留出 harness 上出现性能灾难性崩塌，尽管底层任务知识有所提高。为分离两类监督，作者提出 harness rehearsal：在只携带极少任务知识、但会练习目标接口的轨迹上做蒸馏。单独使用跨 harness 任务监督或 rehearsal 收益都不大，二者结合则远大于各自之和——在 BFCL V3 多轮任务、Qwen3-4B 上分别取得 8.5% 和 32.5%，结合后为 58.8%。作者还报告，on-policy 强化学习比蒸馏更能抵抗单 harness 训练的影响，不会明显损害其他 harness 上的表现，且多 harness 蒸馏获得的接口能力可在后续 RL 中保留。由于目前只有摘要，实验设置、基线、方差与失败分析仍无法深入评估。

**「启示」** 作者的结论是，智能体能力可分解为任务能力与接口能力，二者需要被联合训练和维护；跨 harness 的任务监督配合接口排练，比只强调其中一面更能把已学知识转化为跨接口的可执行表现。

**「方案」** 这篇立场论文把忠实性界定为：思维链不仅人类可读，还要足够反映模型底层推理，以支持负责任的使用。作者综合既有研究指出，模型说出的推理链经常与驱动预测的关键隐藏计算不一致，因此思维链既非可信可解释性的必要条件，也非充分条件。他们分析 1000 篇近期以思维链为中心的论文后发现，约 21.7%明确把思维链当作承重的可解释性技术，构建了在思维链不忠实时就不成立的流程或安全论证，其中包含医学、法律和自主系统等高危领域。基于此，作者提出三项主张：不要在缺少额外验证时把思维链视为充分的可解释性；采用严格方法评估其忠实性是否足以支撑下游决策；在相关可解释性声明旁报告这些评估，同时继续利用思维链的沟通与监控价值。
