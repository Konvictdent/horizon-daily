rss · V2EX · 11月22日 20:12

**「背景」** certifi 是 Python 生态独立维护的 CA 根证书包，许多 Python TLS 客户端用它做证书校验，而不读取 macOS 系统钥匙串或 Homebrew 的 ca-certificates。它随各个 Python 环境安装在 site-packages 中，因此系统更新或 brew 更新不会改动它，只有显式升级 certifi 才会替换其中的根证书清单。
